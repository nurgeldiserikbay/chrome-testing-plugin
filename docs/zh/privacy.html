隐私政策

Chrome 扩展“QA Bug Recorder”。自 2026 年 11 月 22 日起生效。

简要说明

本扩展帮助测试网站。它收集的所有内容只保存在你的浏览器中。扩展没有自己的服务器，不展示广告，不出售也不向第三方提供数据。只有当你自己操作时，数据才会离开浏览器：下载或复制报告，或点击你连接的服务的按钮。

收集哪些数据

仅在你开始检查的标签页上，且仅在检查进行期间：

  • 页面截图，以及标签页视频和麦克风语音——仅在你下达指令时；
  • 页面上的操作：点击、在字段中输入、跳转。不记录密码、银行卡、CVV 和令牌字段的值；
  • 页面技术数据：网络请求和响应、控制台消息、性能指标、cookie 和网站存储数据、环境信息（浏览器、窗口大小）；
  • 你的备注、标记和所选的严重程度。

此外，扩展还会保存你自己创建的内容：自动测试场景、响应模拟规则、API 测试项目及其结果、设置。

数据存储在哪里

存储在你电脑上浏览器的本地存储中（IndexedDB 和扩展存储）。你可以在“我的报告”中删除任意报告，或通过卸载扩展删除全部数据。

何时传输数据

  • 导出和复制。由你决定将下载或复制的报告发给谁。导出前可以隐藏令牌和密码。
  • AI 分析（可选）。如果你填写了自己的服务 API 密钥（Anthropic、OpenAI 或兼容服务），点击 🤖 按钮时，条目或报告的文本以及（如已开启）截图会发送给该服务。此后适用所选服务的隐私政策。密钥只保存在你的浏览器中。
  • Google Docs（可选）。如果你连接了 Google，报告会按你的指令上传到你 Google 云端硬盘中的“QA Bug Recorder”文件夹。扩展只能访问它自己创建的文件。
  • API 测试和自动测试。请求只会发送到你指定的地址。

扩展权限

  • 网站访问——用于记录被测页面上的请求、控制台和操作，并显示标记面板。
  • 标签页捕获和麦克风——用于按你的指令录制视频和语音备注。
  • 存储——用于在浏览器中保存报告。
  • 标签页调试（可选，首次使用时请求）——用于模拟慢速网络和设备、在不同屏幕尺寸下截图以及完整网络捕获。
  • Google 登录——仅在你连接 Google Docs 时使用。

儿童

本扩展面向测试和开发专业人员，不面向儿童。

变更

如果政策发生变更，新版本将发布在本页面并注明日期。

联系方式

关于数据和扩展工作方式的问题：请通过 Chrome 网上应用店中的扩展页面（“支持”）联系。
