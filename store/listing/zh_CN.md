发现缺陷？10 秒记录下来。

QA Bug Recorder 把缺陷变成现成的报告：开启检查，照常使用网站，扩展会收集开发者需要的一切。

错误自动捕获
• 控制台错误或失败的请求会成为独立条目：当时的截图、错误文本、带服务器响应的请求以及之前的操作。
• 忽略第三方脚本（统计、广告、小部件）的错误。

标记你看到的问题
• 元素、箭头、区域或备注——带高亮的截图和你的说明。
• 语音备注，以及附带事件和请求的标签页视频。
• 复现步骤来自你真实的点击、输入和跳转。

开发者能直接用的报告
• Word、Markdown、HTML、HAR 或全部打包；导出到 Google Docs。
• 控制台、网络、性能（Web Vitals）、Cookie 和存储——清晰易懂，无需 DevTools。
• 导出时隐藏令牌、Cookie 和密码。

网站自动检查
SEO、加载速度、无障碍（axe-core）、语义、实践与安全、多余的重新渲染——附评分和修复方法。

测试人员工具
• 从录制生成自动测试，每次发布后运行，导出为 Playwright。
• 基于 Swagger/OpenAPI 和 Postman 的 API 测试：正确、不完整和错误的数据，无令牌，调用链和错误顺序。
• API 响应模拟：错误、空列表、延迟、离线。
• 慢速网络和 CPU、设备模拟、375–1920 px 截图。

AI 分析（可选）
使用你自己的 Claude/OpenAI 密钥：缺陷标题、步骤、可能原因和报告摘要。

隐私
所有数据只保存在你的浏览器中。扩展没有服务器。只有在你下载或复制报告，或使用你自己连接的服务时，数据才会离开浏览器。

界面语言：德语、俄语、法语、哈萨克语、葡萄牙语、西班牙语、英语、中文。
