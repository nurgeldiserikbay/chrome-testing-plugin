Авторизация

Откройте сайт, войдите — расширение найдёт токен в его запросах.

Запросы уйдут с cookie, которые браузер хранит для этого сайта, — войдите на сайт в этом же Chrome.

Цепочка — запросы по порядку с передачей данных: id из ответа на создание подставляется в следующие запросы. Последние шаги проверяют «неправильный порядок»: получить, изменить и удалить уже удалённое (ожидается 404, а не 200 или 500). Выполняются только на тестовом стенде.

🔌 Тестирование API по спецификации

Импортируйте Swagger/OpenAPI или коллекцию Postman — и одной кнопкой проверьте все эндпоинты:

  • ✅ правильные запросы — статус, соответствие ответа схеме, время
  • 🧩 неполные и неверные данные — нет обязательных полей, не те типы, null, длинные строки, не тот формат, битый JSON (ожидается 400/422, а не 500 и не «сохранил»)
  • 🔒 без авторизации и с неверным токеном
  • 🔁 цепочки и порядок: создать → получить → изменить → удалить → получить/изменить/удалить удалённое
  • 💬 «Что не так с API» — понятные объяснения и как исправить
