# QA Bug Recorder — расширение Chrome для фиксации багов

## Установка (2 минуты)
1. Распакуйте архив в постоянную папку (не удаляйте её после установки).
2. Откройте `chrome://extensions`, справа вверху включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `qa-recorder`.
4. Закрепите иконку 🐞 на панели (значок пазла → булавка).
5. **Обновите открытые вкладки** тестируемого сайта: фоновый сбор начинается с загрузки страницы.

Работает в Chrome 116+, Edge, Яндекс Браузере и других браузерах на Chromium.

## Как пользоваться
1. Откройте тестируемый сайт → иконка расширения → **▶ Начать проверку** (или `Ctrl+Shift+Q`). Внизу страницы появится панель.
2. Работайте с сайтом как обычно. Отчёт складывается из **пунктов** трёх видов:
   - **⚠ Ошибка — автоматически.** Ошибка в консоли или запрос с ошибкой → отдельный пункт: скриншот в этот момент, текст ошибки, запрос с телом и ответом сервера, действия перед ошибкой, консоль и запросы рядом. Повторы той же ошибки считаются, а не дублируются. Ошибки чужих скриптов и сервисов (аналитика, реклама, виджеты, другие расширения) не сохраняются — настройка «Только ошибки этого сайта». Лишнюю ошибку можно игнорировать: ⚠ на панели → 🙈 (или 🙈 в отчёте); список — в настройках расширения.
   - **💬 Замечание — когда вы отмечаете проблему сами:** 🎯 Элемент, ➚ Стрелка, ▭ Область или 💬 Заметка. В пункте только скриншот с выделением, текст и голос (если записывали 🎤). Пометки прикреплены к элементам, в покое полупрозрачные; наведите на номер — «✎ Изменить» / «🗑 Удалить». 📋 — список всех пунктов.
   - **🎬 Запись — когда нажали «⏺ Записать видео».** Видео плюс события, действия, запросы и консоль за время записи и 1–2 минуты до неё.
   - **🩺 Автопроверка страницы** — кнопка на панели: доступность (axe-core), изображения, DOM. Текущая страница проверяется и автоматически при завершении. Сеть, перерисовки и предупреждения анализируются по данным всей проверки.
   - **Серьёзность** замечания выбирается при сохранении; у ошибок подбирается автоматически.
   - **▁** сворачивает панель в маленький значок; «✓ Готово» завершает проверку вторым нажатием.
3. **✓ Готово** — откроется отчёт: список пунктов по порядку, у каждого только свои данные. Любой пункт можно скопировать («📋 Копировать»: текст для задачи, скриншот или всё вместе) или скачать отдельно («⬇ Скачать пункт») — удобно заводить одну задачу на пункт. Все данные сессии целиком — в свёрнутом разделе «📂 Все данные сессии».
4. Выгрузка всего отчёта: **Word**, **Markdown (.zip)**, **HTML**, **HAR** или всё одним архивом. В «⚙ Что включать в отчёт» можно отключить виды пунктов или добавить приложение со всеми данными.

## Горячие клавиши
| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+Q` | Начать проверку / открыть панель |
| `Alt+Shift+E` | Выбрать элемент |
| `Alt+Shift+A` | Стрелка |
| `Alt+Shift+S` | Готово, открыть отчёт |

Переназначить: `chrome://extensions/shortcuts`.

## Безопасность данных
- Всё хранится локально в браузере (IndexedDB).
- Значения полей паролей, карт, CVV, токенов не записываются вообще.
- В AI-сервис или Google Drive данные уходят, только когда вы нажимаете соответствующую кнопку.
- При экспорте по умолчанию скрываются заголовки `Authorization`, `Cookie`, `Set-Cookie`, API-ключи, а также поля `password`, `token`, `secret` и т.п. в URL и телах запросов.

## Настройки (в окне расширения)
- **Сразу включать видео** при начале проверки.
- **Звук вкладки** в видео.
- **Считать перерисовки React** — дополнительный счётчик по компонентам React (лишние перерисовки DOM считаются на любом сайте и без этой настройки). Включено по умолчанию. Выключите, если пользуетесь расширением React DevTools: они мешают друг другу.
- **Полный захват сети** через DevTools-протокол: все ресурсы (картинки, скрипты), CORS-ошибки, предупреждения браузера. Chrome покажет жёлтую полосу «отлаживается» — это нормально.
- Сколько минут брать из фонового буфера (1–15).

## Инструменты: автотесты, подмена API, условия
В окне расширения, блок «Инструменты».

**🤖 Автотесты.** Откройте начальную страницу → «Записать автотест». Сверху появится панель записи: выполняйте сценарий как пользователь, затем добавьте проверки — «✓ Проверка» (кликнуть по элементу: виден / содержит текст / значение поля), «🔗 Адрес», «🔤 Текст». «💾 Сохранить» — сценарий попадёт на страницу «▶ Автотесты». Там: запуск выбранных или всех, результаты по шагам со скриншотом падения, история, отчёт в HTML, скачивание тестов Playwright. Сценарий можно поправить: изменить значения, отключить, переставить или удалить шаги.

Советы: ставьте проверки на результат («Заказ оформлен», имя в шапке), а не только клики; попросите разработчиков добавить `data-testid` важным кнопкам — тесты станут устойчивее. Загрузку файлов и капчу автотест не повторяет.

**🔌 API-тесты.** «🔌 API-тесты по Swagger / Postman» → «＋ Импортировать» (файл, ссылка на swagger.json или вставить текст). Во вкладке «Окружение» укажите базовый адрес стенда и авторизацию (или «🔑 Взять из открытой вкладки» — сначала войдите на сайт). Галочка «Это тестовый стенд» разрешает POST/PUT/PATCH/DELETE и цепочки — **не включайте её для прода**. «▶ Запустить проверки» → вкладка «Результаты»: что не так с API, почему это плохо и как исправить, запрос и ответ каждой проверки. Тело правильного запроса можно поправить во вкладке «Эндпоинты», цепочки — собрать или переставить во вкладке «Цепочки» (извлечение: `userId=$.id`, параметры пути: `{id}={{userId}}`).

**🧪 Подмена API.** «🧪 Подмена API» → выберите запрос из списка последних (подставится настоящий ответ) или впишите часть адреса → «Вернуть ответ» (статус, тело), «Задержать» или «Ошибка сети». Пока правило включено, на странице видна фиолетовая плашка. Не забудьте выключить подмену после проверки.

**📶 Условия и 📐 Экраны.** «📶 Условия» — сеть, процессор и устройство для текущей вкладки (Chrome покажет полосу «отлаживается»). «📐 Экраны» — скриншоты страницы на четырёх ширинах пунктами в отчёт.

## Язык интерфейса
Английский, испанский, казахский, китайский, немецкий, португальский, русский или французский: окно расширения → «Настройки» → «🌐 Язык / Language». По умолчанию — как в браузере. Отчёты и выгрузки формируются на выбранном языке.

## Первый запуск и разрешения
После установки откроется страница приветствия: прочитайте, какие данные собирает расширение, и нажмите «Понятно, начать работу» — без этого проверка не запустится. Разрешение «Отладка вкладки» (`debugger`) используется только когда вы включаете условия сети/устройства, скриншоты экранов или полный захват сети. Chrome не позволяет сделать его необязательным, поэтому при установке он предупреждает, что расширение может «читать и изменять данные на всех сайтах».

## Интеграции: AI и Google Docs
Иконка расширения → **🔌 Интеграции** (или ссылка вверху отчёта).

**🤖 AI-разбор.** Выберите сервис (Claude, OpenAI или совместимый: OpenRouter, Groq, локальная модель), вставьте API-ключ, нажмите «Проверить подключение». В отчёте у каждого пункта появится рабочая кнопка **🤖 AI**, сверху — **🤖 Резюме отчёта**. Данные уходят в сервис только по нажатию; токены и пароли маскируются. Без ключа кнопка копирует готовый запрос — вставьте его в Claude или ChatGPT.

**📄 Google Docs.** Без настройки кнопка «Google Docs» копирует отчёт и открывает новый документ — нажмите Ctrl+V. Для выгрузки в один клик кто-то в команде один раз создаёт Client ID в Google Cloud — пошаговая инструкция прямо на странице интеграций. Всем тестировщикам вставляется один Client ID; адрес «Authorized redirect URI» у каждого свой (его показывает страница), все адреса добавляются в один клиент.

## Известные ограничения
- Видео можно включить с панели на странице, только если баг начат через иконку или горячую клавишу на этой же вкладке и после этого не было перехода на другую страницу (так требует Chrome). Если появится подсказка — нажмите иконку → «⏺ Видео».
- Видео сохраняется в WebM. Открывается в Chrome, VLC и плеерах Windows 10+/macOS 13+. В Word видео не встраивается, оно идёт отдельным файлом.
- В DevTools у сообщений консоли источником может отображаться `inject.js`: так устроен перехват. На работу сайта это не влияет.
- На служебных страницах (`chrome://`, Chrome Web Store) расширения не работают.
