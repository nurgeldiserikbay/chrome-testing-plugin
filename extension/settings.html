Интеграции

Подключите AI для разбора багов и Google Docs для выгрузки отчётов. Всё необязательно: без настроек расширение работает как раньше.

🤖 AI-разбор багов

Кнопка 🤖 AI у каждого пункта отчёта: AI оформит баг (заголовок, шаги, ожидалось / фактически), предложит серьёзность, подскажет вероятную причину — фронтенд или бэкенд — и что проверить разработчику. Для всего отчёта — 🤖 Резюме: что исправлять в первую очередь.

🔒 Ключ хранится только в этом браузере. Данные пункта (текст, запросы, скриншот) отправляются выбранному сервису только когда вы нажимаете 🤖. Пароли и токены в запросах перед отправкой маскируются. Без ключа кнопка 🤖 копирует готовый запрос — его можно вставить в Claude или ChatGPT вручную.

📄 Google Docs

Кнопка Google Docs в отчёте: отчёт или отдельный пункт сразу появляется как Google-документ со скриншотами в папке «QA Bug Recorder» на вашем Диске. Видео и голос загружаются рядом, ссылки на них — в документе. Расширение видит только файлы, которые создало само.

Без настройки кнопка тоже работает: копирует отчёт и открывает новый документ — останется нажать Ctrl+V.

Как получить Client ID (один раз на команду, ~5 минут)
  1. Откройте Google Cloud Console и создайте проект, например «QA Bug Recorder».
  2. В библиотеке API включите Google Drive API.
  3. Откройте Google Auth Platform → «Начать»: название приложения, ваша почта, тип аудитории External (или Internal, если у компании Google Workspace).
  4. В разделе Audience добавьте почты тестировщиков в Test users. Либо нажмите Publish app — доступ только к своим файлам (drive.file) не требует проверки Google.
  5. В разделе Clients → Create client → тип Web application. В Authorized redirect URIs добавьте адрес ниже. У каждого, кто поставил расширение из своей папки, адрес свой — добавьте адреса всех тестировщиков в один и тот же клиент.
  6. Скопируйте Client ID и вставьте в поле ниже. Всем тестировщикам вставлять один и тот же.
